# orbit-research

Scientific claims, protocols, evidence and assessments, with reproducible workflows powered by Orbit.

This repository owns the shared scientific record schemas, validators, importers, local research browser and Orbit integration. Principia, Parallax, Orrery and Astrolabe retain their own scientific records and artifacts. Orbit remains authoritative for operational tasks, crews, runs and delivery.

The approved starting contract is recorded in Constellation task ORB-11353. This is the initial repository scaffold; implementation and migration proceed through scoped Orbit tasks.
